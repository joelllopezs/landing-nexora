# NEXORA — Gestão Financeira Inteligente

**Mais clareza para suas finanças. Mais inteligência para suas decisões.**

A Nexora é uma empresa fictícia de tecnologia que apresenta uma plataforma inteligente de gestão financeira desenvolvida para pequenas e médias empresas.

O projeto foi criado para demonstrar uma experiência digital moderna, intuitiva e profissional, com foco na organização financeira, visualização de indicadores e controle de operações empresariais.

---

## Sobre o projeto

A proposta da Nexora é simplificar a gestão financeira empresarial por meio de uma plataforma que reúne informações importantes em um único ambiente.

Com uma interface moderna e recursos apresentados de forma visual, a solução demonstra como empresas podem acompanhar seu desempenho financeiro e tomar decisões com mais clareza.

## Funcionalidades apresentadas

- **Dashboard financeiro:** visão geral dos principais indicadores da empresa.
- **Fluxo de caixa:** acompanhamento de entradas e saídas financeiras.
- **Contas a pagar e receber:** organização dos compromissos financeiros.
- **Relatórios:** visualização de informações e desempenho financeiro.
- **Indicadores:** acompanhamento de métricas importantes para o negócio.
- **Planos:** apresentação das opções comerciais da plataforma.
- **FAQ interativo:** respostas para dúvidas frequentes.
- **Formulário de contato:** canal demonstrativo para solicitação de uma apresentação.
- **CTA de demonstração:** chamadas estratégicas para conversão.

## Como executar o projeto

**1. Clone o repositório**

```bash
git clone URL_DO_REPOSITORIO
```

**2. Acesse a pasta**

```bash
cd nexora
```

**3. Instale as dependências**

```bash
npm install
```

**4. Execute em ambiente de desenvolvimento**

```bash
npm run dev
```

**5. Gere a versão de produção**

```bash
npm run build
```

## Objetivo do projeto

A Nexora é um projeto demonstrativo de portfólio, desenvolvido para apresentar conceitos de desenvolvimento frontend, design de interfaces e construção de experiências digitais para produtos SaaS.

Os dados, indicadores, depoimentos e informações comerciais apresentados possuem finalidade demonstrativa e não representam uma operação financeira real.
